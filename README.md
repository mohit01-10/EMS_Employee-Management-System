## Features 

- Add Details such as Name, EmailID, Phone, Status & Department.
- Uses single form to add details one at a time as well as Bulk user registration using Excel sheet
- Admin cam view all Employees data on Home Page and perform actions.
- Update Existing Details using the same form with prefilled previous data.
- Delete any Employee Detail with single click and auto Serial No. adjustment.
- Users can Chat and send messages using DMs.
- Documents related to employees such pay-slips,appraisal reports, etc can be uploaded and view.
- Login-Logout history
